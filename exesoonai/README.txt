SoonAI Portable Executable

This folder contains a packaged Windows executable build for SoonAI.

How to use:
1. Open the folder exesoonai
2. Run soonai.exe
3. If Windows asks for permission, click More info > Run anyway

This executable is generated from the Node.js CLI in the project root.
It does not require Python to run.

Files in this folder:
- soonai.exe - the single executable program

Notes:
- The app stores local project data in the current working directory.
- You can copy this executable to another machine or folder for convenience.
